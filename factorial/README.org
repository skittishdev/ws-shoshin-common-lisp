This document provides an opinionated overview of how to setup a basic Common Lisp project using sbcl + asdf + quicklisp + nix (the package manager).

We use =factorial= as the project name.

* Basic setup.
Create/copy the following files:
- =flake.nix=
- =.envrc=

* Development commands.
** Install and configure quicklisp.
https://www.quicklisp.org/beta/
*** Download quicklisp, and open in sbcl.

#+BEGIN_SRC shell
curl -O https://beta.quicklisp.org/quicklisp.lisp
sbcl --load quicklisp.lisp
#+END_SRC

*** Install quicklisp.

#+BEGIN_SRC lisp
(quicklisp-quickstart:install)
#+END_SRC

*** Configure quicklisp to always load.

#+BEGIN_SRC lisp
(ql:add-to-init-file)
#+END_SRC

** Create packaging and build files.

#+BEGIN_SRC shell
touch factorial.asd
touch packages.lisp
touch build.lisp
#+END_SRC

** Create a folder to hold source code.

#+BEGIN_SRC shell
mkdir lisp
#+END_SRC

** Quicklisp support.
*** Create a symlink in quicklisp folder.

#+BEGIN_SRC shell
ln -sf $PWD ~/quicklisp/local-projects/factorial
#+END_SRC

*** Add local project to quicklisp.

#+BEGIN_SRC lisp
(ql:register-local-projects)
#+END_SRC

*** Load the system.

#+BEGIN_SRC lisp
(ql:quickload :factorial)
#+END_SRC

** Build standalone executable.
See the Makefile.

#+BEGIN_SRC shell
make install
#+END_SRC

An alternative target to build with ASDF is also provided in the Makefile.

#+BEGIN_SRC shell
make install-with-asdf
#+END_SRC
